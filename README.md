# STM32 + MAX30102 血氧仪开发项目

基于 STM32F103C8T6 和 MAX30102 的嵌入式学习项目，目标是逐步实现光电容积脉搏波（PPG）采集、心率检测和血氧饱和度估算。本仓库保存开发中的阶段成果，尚未完成血氧仪的全部功能。

## 开发方式与个人贡献

本项目采用 AI 辅助学习：AI 提供代码框架、注释和 TODO 任务，我在框架中完成对应代码实现。STM32 外设初始化与基础工程使用 STM32CubeMX / STM32 HAL。保留 TODO 和教学注释，便于展示实现过程与后续进度。

当前源码包含寄存器配置、FIFO 数据读取与拼接、去直流和低通滤波等实现；这份列表描述代码现状，不代表所有代码均由我独立原创。具体分工以以上开发方式说明为准。

## 硬件与接线

主控：STM32F103C8T6；传感器：MAX30102 模块。

| STM32 引脚 | 工程中的用途 |
| --- | --- |
| PB6 | I2C1 SCL，连接传感器 SCL |
| PB7 | I2C1 SDA，连接传感器 SDA |
| PA9 | USART1 TX，连接 USB 转串口模块 RX |
| PA10 | USART1 RX（工程已配置） |
| PA13 / PA14 | SWDIO / SWCLK，用于下载调试 |

各模块需要共地。传感器模块的供电和 I2C 电平请依据实际模块规格确认，接线表未确认具体模块的供电设计。

## 编译、下载与观察

1. 使用 Keil MDK 打开 `MDK-ARM/MAX30102.uvprojx`，安装工程需要的 STM32F1 设备支持包与 ARM 编译器。
2. 执行 Build，连接适配的 SWD 下载器，并按实际硬件设置下载及调试选项。
3. 串口设置为 **115200 波特率、8 位数据、无校验、1 位停止位**。
4. 观察每行四列数据：`red_raw,ir_raw,red_filtered,ir_filtered`。后两列为去直流后经过低通滤波的值。
5. 调试时可以观察 `part_id`、`id_status`、`config_status`、`sample_count` 等变量；心跳检测 TODO 未完成前，不应把 `beat_count` 当作有效检测结果。

CubeMX 配置文件为 `MAX30102.ioc`。源码注释将采样设置目标描述为 100 Hz；实际采样与数据质量需要通过硬件验证。
