# STM32 + MAX30102 血氧心率数据采集开发学习项目

基于 STM32F103C8T6 和 MAX30102 的嵌入式学习项目，目标是逐步实现光电容积脉搏波（PPG）采集、心率检测和血氧饱和度估算。本仓库保存开发中的阶段成果，尚未完成血氧仪的全部功能。

## 开发方式与个人贡献

本项目全程采用 AI 辅助学习，前期后期方法不同：1 前期：AI 提供代码框架、注释和 TODO 任务，我在框架中完成对应代码实现。2 后期：我给AI后续需要实现的需求以及需要使用的硬件，AI给我思路，我独立来写框架和实现代码；询问AI三次后，回到前期使用方法即AI提供框架，目前还未触发此机制。STM32 外设初始化与基础工程使用 STM32CubeMX / STM32 HAL。

当前源码包含寄存器配置、FIFO 数据读取与拼接、去直流、低通滤波、心率计算与 SpO2 估算等实现；这份列表描述代码现状，不代表所有代码均由我独立原创。具体分工以以上开发方式说明为准。

## 硬件与接线

主控：STM32F103C8T6；传感器：MAX30102 模块。

| STM32 引脚 | 工程中的用途 |
| --- | --- |
| PB6 | I2C1 SCL，连接传感器 SCL |
| PB7 | I2C1 SDA，连接传感器 SDA |
| PA9 | USART1 TX，连接 USB 转串口模块 RX |

## 编译、下载与观察

1. 使用 Keil MDK 打开 `MDK-ARM/MAX30102.uvprojx`，安装工程需要的 STM32F1 设备支持包与 ARM 编译器。
2. 执行 Build，连接适配的 SWD 下载器，并按实际硬件设置下载及调试选项。
3. 串口设置为 **115200 波特率、8 位数据、无校验、1 位停止位**。
4. 上位机观察每行八列数据：`red_raw,ir_raw,red_filtered,ir_filtered,heartbeat_marker,heart_rate_bpm,spo2_est,spo2_valid`。第三、四列为去直流后经过低通滤波的值；第五列为心跳显示标记；第七列为保留一位小数的 SpO2 估算值。
5. 无效心率输出 0；无效 SpO2 输出 0，且 `spo2_valid` 为 0。有效标志表示通过程序内的检查，不代表测量精度已验证。调试时可观察 `part_id`、`id_status`、`config_status`、`sample_count`、`beat_count` 等变量。
6. 每 5 组成功采样输出一行；采样接近 100 组/秒时，约为 20 行/秒。使用 VOFA 观察波形时，将每行时间间隔设为约 **50 ms**，并确认窗口正在查看最新数据。第五列心跳标记在待发送事件存在时为 `10000`，否则为 `0`。

SpO2 估算使用窗口内红光与红外光的峰峰值及直流均值计算比值 R，再代入 `-45.060 × R² + 30.354 × R + 94.845`。源码注释记录了公式参考链接；当前实现的精度、运动干扰与校准仍需通过实验验证。

CubeMX 配置文件为 `MAX30102.ioc`。源码注释将采样设置目标描述为 100 Hz；实际采样与数据质量需要通过硬件验证。
